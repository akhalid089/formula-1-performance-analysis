# Data

This project uses historical Formula 1 race data.

The following files were used:

- races.csv
- results.csv
- drivers.csv
- constructors.csv
- qualifying.csv

The raw data is not included in this repository.

## Source

The dataset can be downloaded from:
kaggle: https://www.kaggle.com/datasets/rohanrao/formula-1-world-championship-1950-2020
